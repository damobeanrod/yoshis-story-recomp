# Handover — Yoshi's Story recomp

Last updated 2026-10-05.

## Status: done (playable)

The game boots, renders (3D and S2DEX 2D), plays sound, takes keyboard and
controller input with rumble, saves (16K EEPROM), and gets through the
title, story book, menus and levels. On top of that:

- a settings launcher before the game (resolution, supersampling, MSAA,
  2D upscaling, output filter, CRT filter, overscan crop, fullscreen), saved
  to `data/settings.ini`, with `YOSHI_*` env overrides;
- F10 cycles the CRT filter, F11 / Alt+Enter toggles fullscreen;
- an app icon and desktop entry (`tools/install_desktop.sh`).

Three RT64 patches (`patches/rt64/`) carry the renderer work; they are the
main thing worth upstreaming (see **Upstreaming** below).

Git history has the full investigation (black screen, stalls, audio, input,
sprites). This document keeps only what's needed to build, maintain and
upstream it.

## Build pipeline
Decomp (inside `nix-shell ../yoshis-story-recomp/tools/decomp-shell.nix`, in
`~/git/yoshis-story-matching`):
```bash
make extract && make -j16        # ends with build/yoshisstory-us.z64: OK
```
Recomp (inside `nix-shell tools/recomp-shell.nix`, in this repo):
```bash
ELF=~/git/yoshis-story-matching/build/yoshisstory-us.elf
python3 tools/check_elf_matches.py --elf $ELF --rom data/yoshis_story.z64   # OK
# only if the ELF changed:
python3 tools/gen_function_sizes.py --elf $ELF --config config.toml
# N64Recomp itself (once):
cmake -S ../N64ModernRuntime/N64Recomp -B build-n64recomp -DCMAKE_BUILD_TYPE=Release
cmake --build build-n64recomp --target N64Recomp -j16
# whenever config.toml or the ELF changed:
python3 tools/regen.py
cmake -B build && cmake --build build -j16
./build/yoshis_story_recomp
```
- Only `src/` changed → `cmake --build build -j16`.
- A patch in `patches/rt64/` changed → `git -C rt64 checkout -- .` then
  `cmake -B build` (CMake applies each patch that applies cleanly).
- To edit RT64: apply the patches, edit the submodule, and regenerate the
  patch you touched as a diff against the tree with the earlier patches
  applied (patches stack: 0002 and 0003 assume 0001/0002).
- Commit regenerated `recomp_funcs/` + `config.toml` after a regen.

## Tools (`tools/`)
| Script | Purpose |
|---|---|
| `check_elf_matches.py` | ELF vs ROM: func names at their address + `.main` bytes identical |
| `find_overlays.py` | Find all .ovl in ROM; emit splat `overlays.yaml` + `overlay_sections.txt` |
| `gen_function_sizes.py` | Size size-0 asm functions; an overlay's last function is clipped at `vramStart + textSize` from its reloc header |
| `regen.py` | Run N64Recomp, auto-stub functions it fails on, then the three fixers |
| `fix_zero_reg_loads.py` | `0 = MEM_W(...)` for `lw $zero` → `(void)(...)` |
| `fix_overlay_relocs.py` | Drop reloc entries with unknown type (`.type =  }`) |
| `fix_missing_overlay_relocs.py` | Relocate overlay HI16/LO16 pairs the ELF has no relocation for, using the ROM's own overlay reloc tables (needs the ROM) |
| `find_invalid_funcs.py` | rabbitizer scan for INVALID instructions (used by `regen.py`) |
| `gen_aspmain.py` | ROM → `rsp/aspMain.toml`, runs RSPRecomp, patches undefined labels |
| `gen_icon.py` | Draws the icon → `assets/icon.png` + `src/icon_data.h` |
| `install_desktop.sh` | Installs the `.desktop` entry + icon (Wayland window icon, app menu) |
| `decomp-shell.nix` / `recomp-shell.nix` | NixOS build environments |

## Why things are the way they are (don't undo these)
1. **Matching ELF only.** A non-matching ELF shifted 549 functions by +0x10;
   N64Recomp takes code from the ELF but librecomp loads data from the ROM,
   so everything drifted. Every early "fix" (delegators, stubs, gameMgr
   clamps, DL injection) papered over that. Never bring those back.
2. **`-fno-strict-aliasing` on `game_funcs`.** `MEM_W`/`MEM_HU`/`MEM_B` pun
   the same bytes through different types; GCC -O2 elided a reload.
3. **Boot state** seeded in `on_init`. The game checks values IPL3 leaves
   behind and silently sabotages itself otherwise:
   | Address | Value | Effect if wrong |
   |---|---|---|
   | 0xA4000000 DMEM[0] | 0xFFFFFFFF | cast types never set (castManager.c:588) |
   | 0xA4001000 IMEM[0] | 0x000017D8 | flag 0x800A5AD0 |
   | 0x80000310 osCicId | 0x000017D8 | flag 0x800A6EB4 |
   | 0xA0000164 | 0x01EC6021 | flag 0x800A6EB8 |
   | 0xA00002B8 | 0x8941680C | flag 0x800A62F0 |
4. **Cart ROM mapped word-swapped at 0x90000000/0xB0000000.**
   `func_8006F500` reads ROM 0x458/0x45C directly and `func_80064AD4`
   compares with 0x0260BCD5; on mismatch input is blanked every frame.
5. **kseg1 aliased onto kseg0** (memfd, `MAP_SHARED|MAP_FIXED`). In the recomp
   0xA0… and 0x80… are separate memory; the game writes audio command lists
   through 0xA0… while the RSP reads the kseg0 view (silence otherwise).
6. **Audio:** `func_8000AD10` is osAiSetNextBuffer (unnamed, so recompiled
   from the game's copy writing AI registers); a hook hands buffers to the
   runtime. The audio microcode (ROM 0x94E60, linked at IMEM 0x1000, jump
   table at data+0x10) is recompiled to `rsp/aspMain.cpp`.
7. **Save type `Eep16k`.** `eepmgr_Probe` parks forever on anything else.
8. **Overlays** (`config.toml`): `relocatable_sections_path`,
   `bss_section_suffix = "_bss"`, `Overlay_Load` hook → `load_overlays`.
   Overlays link at real KSEG0 addresses (0x80400040..0x807C6D00).
   `fix_missing_overlay_relocs.py` fixed the level-2 crash
   (castManager.c:161): 16 lui/addiu pairs splat didn't symbolize.
9. **RT64 `send_dl` loads the task's GBI every task** (`loadUCodeGBI(..., true)`):
   DLs switch F3DEX.NoN 1.23 ↔ S2DEX 1.06 mid-list with G_LOAD_UCODE.
10. **S2DEX framebuffer fast path disabled** (`YOSHI_BG_FASTPATH=1` restores):
    it drew stale framebuffer data for G_BG_1CYC level backgrounds.
11. **Display settings applied after `app->setup()`**: setup loads RT64's
    `rt64.json` and would overwrite them. MSAA changes call
    `updateMultisampling()`.
12. **Launcher**: separate SDL_Renderer window destroyed before the Vulkan
    window. RT64's custom ImGui SDL2 backend has no controller support, so the
    launcher feeds controller nav itself; it eats the startup
    controller-added events, so `main()` calls `input_open_controller()`
    after it. Its window is created hidden and sized again after the
    renderer exists and after the first frame (Wayland opened it small).
13. **Data folder**: `YOSHI_DATA_DIR`, else `data/` beside the executable,
    else `../data`; the executable path comes from `/proc/self/exe`. CMake adds
    the Vulkan loader's directory to the RUNPATH (RT64 dlopen()s it), so the
    binary starts outside nix-shell. Moving machines = rebuild (README).
14. **Window icon on Wayland** comes from the `.desktop` file matched by app id
    `yoshis-story-recomp` (SDL hints set before `SDL_Init`).

## RT64 patches (what they do)
- **0001-s2dex-object-sprites** — upstream RT64 never draws GBI1 S2DEX object
  sprites (G_OBJ_RECTANGLE / SPRITE / RECTANGLE_R / MOVEMEM unmapped,
  LDTX_* are TODOs). Implements them as RDP texrects using the microcode's
  fixed-point formulas (render-mode corrector tables, identity default
  matrix, one texel per sprite pixel, cancels `drawRect`'s vFractionOffset),
  rotated sprites via a new `RDP::drawTexQuad`, and resets S2DEX state on
  task start / G_LOAD_UCODE.
- **0002-edge-crop** — `EnhancementConfiguration::presentation.edgeCrop`: VI
  renderer enlarges the view so N framebuffer pixels per edge fall outside
  (TV overscan). The game leaves a stale 1-px border; default 2.
- **0003-crt-filter** — CRT look in `VideoInterfacePS.hlsl` (Gaussian scanlines
  on native lines lit by each line's average colour, brightness-dependent
  beam width, 3-px aperture grille, fades out below ~3 window px per line);
  `presentation.crtStrength` plumbed PresentQueue → VIRenderer → push
  constants (`VideoInterfaceCB` gains `crtStrength`, `nativeResolution`).

## Upstreaming (later)

### RT64 (github.com/rt64/rt64)
1. **S2DEX GBI1 object commands (patch 0001)** — biggest value; any GBI1
   S2DEX game benefits. Before a PR:
   - split `RDP::drawTexQuad` into its own commit;
   - test other S2DEX 1.0x games and check the GBI2 S2DEX path (S2DEX2 maps
     the same commands differently) can share the code;
   - the formulas come from olivieryuyu's microcode decoding; GLideN64
     (GPL) was only a reference — keep the implementation independent and
     credit the decoding work;
   - the vFractionOffset cancel and status reset may need discussion with
     the maintainers (they touch shared RDP/S2DEX state).
2. **Framebuffer fast-path bug** — report an issue: for this game the G_BG_1CYC
   fast path matches a tracked framebuffer overlapping the CPU-unpacked
   background images (around RDRAM 0x286940) and draws stale data. Repro:
   `YOSHI_BG_FASTPATH=1`, start a level.
3. **Edge crop (patch 0002)** — general overscan option; would need a config
   UI entry and JSON serialization to fit RT64's config system.
4. **CRT filter (patch 0003)** — feature PR; only SPIR-V was compiled/tested,
   check DXIL (D3D12) and Metal builds, add it to the config UI, and decide
   on push-constant layout vs a separate constant buffer.

### N64Recomp (github.com/N64Recomp/N64Recomp)
- `lw $zero, …` emits `0 = MEM_W(…)` (invalid C) — `fix_zero_reg_loads.py`.
- ELF reloc types > 7 index past `reloc_names` → empty `.type =` —
  `fix_overlay_relocs.py`.
- RSPRecomp: fails on a toml path with an empty directory component (pass a
  full path); emits gotos to undefined labels when the text tail is data
  (`gen_aspmain.py` rewrites them to `UnhandledJumpTarget` returns) — an
  option to stop at a size or emit that return would remove the patcher.

### N64ModernRuntime (github.com/N64Recomp/N64ModernRuntime)
- Recommend/apply `-fno-strict-aliasing` for generated code.
- kseg1 (0xA0…) should alias kseg0 RDRAM in the runtime (our memfd hack in
  `on_init`).
- Map cart ROM (0x90…/0xB0…) for direct reads, word-swapped to the runtime's
  memory layout.
- Set the IPL3 boot state (osCicId at 0x80000310, SP DMEM/IMEM first words)
  like hardware leaves it.

### Decomp (decompals/yoshis-story)
- Split overlays (`find_overlays.py` output) + auto-symbol ld files on the
  link line (the local changes above).
- Name `func_8000AD10` = osAiSetNextBuffer, `func_8006F500` (cart ROM read),
  and the anti-piracy checks (`func_80064AD4`, `func_80064920`).
- Symbolize the overlay lui/addiu pairs `fix_missing_overlay_relocs.py`
  rewrites (run it and read its output for the list).
- Overlay function sizes: the last function per overlay ends at text end,
  not section end.

## Known loose ends
- N64Recomp LO16 warnings (6) in `.ovl_BA4640` (4), `.ovl_CD51E0`,
  `.ovl_EAF270`: check those functions if those overlays misbehave.
- No `unload_overlays` when the game frees an overlay's heap block (stale
  func_map entries). Hook the free path if overlay reuse ever misbehaves.
- `osMemSize` is 8MB (librecomp default); Yoshi is a 4MB game.
- Re-run the boot-state scan over the overlays (`lui 0x8000/0xA000/0xA400` +
  loads of low addresses in `recomp_funcs`); none found missing in play.
- `rsp->reset()` runs once in `send_dl`; Zelda64Recomp resets every task.
- `data/saves/*.bin` and `data/mods.json` are tracked in git; consider
  `git rm --cached` + ignore (that keeps the local files).

## Debugging recipes
- `[game]` (osSyncPrintf hook; `YOSHI_SYNCPRINTF=0` silences) and
  `[HungUp] file:line` + native backtrace (Fault_HungUp hook; castManager.c:161
  also lists the missing cast id and loaded casts). Use `grep -a` (SJIS).
- **Finding a HungUp site:** line N is `addiu $a1, $zero, 0x<N hex>` in the
  delay slot of `jal 0x80071380`; search `recomp_funcs/*.c` comments.
- **Tracing:** add a `[[patches.hook]]` (`func`, optional `before_vram`,
  `text = "yoshi_xxx(rdram, ctx);"`), helper in `src/main.cpp`, prototype in
  `src/ignored_funcs.h`, then `tools/regen.py` + rebuild. `vram_u32/u8/cstr`
  read RDRAM by VRAM.
- `YOSHI_WATCH_ADDRS=0x…,0x…` logs changes to RDRAM words; F9 dumps the next
  frame's display list (S2DEX structs included); `YOSHI_DLDUMP=N` histograms.
- Hang: attach gdb (`sudo gdb -p $(pgrep yoshis_story) -batch -ex "thread
  apply all bt 25"`). A game thread in `pause_self` is an "impossible"
  `while(1)` in the game — read that function's condition.
- Crash: the SIGSEGV handler prints the faulting VRAM and a backtrace (game
  functions are named thanks to `-rdynamic`); SIGUSR1 makes a thread print
  its backtrace.

  Main_InitSubsystems 0x800687B8, osAiSetNextBuffer (func_8000AD10)

- Input: runtime pad 0x8010E1D0 → padmgr record 0x8010E170 → game copy
  0x8010DEE0 (held) / 0x8010DEEC (pressed)
